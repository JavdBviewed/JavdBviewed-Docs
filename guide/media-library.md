# 浏览器扩展媒体库

## 概览

扩展仪表盘的「媒体库」汇集已配置的 Emby、Jellyfin 和 115 片库目录。它读取同步到扩展本地的媒体索引，按影片浏览来源副本、观看状态和播放进度；播放时仍需要对应媒体服务或 115 账号可用。

这里的「同步资料库」更新影片信息与播放状态，**不是**把影片文件下载到浏览器。扩展的 [Cloud 记录同步](/guide/cloud-sync) 也不是媒体库来源，不能代替 Emby、Jellyfin 或 115 的连接与索引。

本页只适用于浏览器扩展。桌面端的[本地媒体库扫描](/desktop/local-library)读取设备上的文件，不等于扩展媒体库索引；浏览器网页上的 [Emby 增强](/guide/emby-integration)则是站点联动入口，不等于仪表盘中的整个媒体库。

## 准备媒体来源

可以只配置一种来源，也可以同时配置多种：

1. **Emby / Jellyfin：**在扩展仪表盘打开 `设置 → 资料库设置`，配置可访问的媒体服务器和账号凭据，启用资料库同步与入库状态。扩展需要服务器地址及有效令牌才能列出同步目标、读取索引和在扩展内取流。已有 Emby 站点联动设置的用户，可参考 [Emby 集成](/guide/emby-integration)，但仍需确认资料库同步开关已启用。
2. **115：**到 `设置 → 115网盘` 完成授权，启用 115 功能并选择片库根目录。仅授权离线下载、未配置片库目录，不会产生可同步的 115 片库目标。授权及目录配置见 [115 网盘集成](/guide/115-drive)。
3. 回到 `媒体库`，点击「同步资料库」，在「选择同步范围」中勾选目标服务器或 115 目录，再点击「同步全部来源」或「同步已选来源」。等待同步完成后查看索引更新时间和条目数。

若「同步资料库」按钮不可用，而同步目标包含 Emby / Jellyfin，请回到「资料库设置」启用「资料库同步与入库状态」。只有 115 目标时不需要打开 Emby 的同步总开关。

::: tip
媒体库显示本地索引快照；首次配置或服务器内容变动后，需要重新同步资料库才能看到最新内容。选择范围只影响本次同步，不会删除其他来源的配置。
:::

## 浏览与播放

- 用「来源」选择全部来源或已配置的具体来源；用「状态」切换全部状态、在看、已看、未看完。两个条件可同时使用。
- 搜索框支持按番号、标题或服务器名称查找。无结果时先清空搜索，再切回「全部来源」和「全部状态」。
- 「封面」可切换缩略图、海报和背景图；「视图」可调整封面类型、卡片尺寸及显示字段。这些设置只影响展示，不改动媒体文件。
- 已有播放进度的影片可在「继续观看」中续播。点击影片卡片打开扩展内详情；点击卡片上的「播放」在弹窗播放器中播放。有多个来源副本时，按播放入口提供的来源选择操作。
- Emby / Jellyfin 播放使用扩展设置中的服务器令牌取流，不要求先在网页中登录对应服务器。115 播放需要 115 授权与可取得的媒体流；详情或卡片上的「在 115 搜索并播放」可用于寻找对应文件。

在线播放取决于来源服务是否可达、授权是否有效以及具体文件是否可播放。媒体库能列出条目，不代表每个来源副本都能直接播放。

## 常见问题

### 媒体库显示「还没有同步任何媒体库内容」

先检查服务器或 115 目录是否已配置，然后运行「同步资料库」。若选择面板提示没有可同步的来源，请检查 Emby / Jellyfin 服务器地址和令牌，或确认 115 已启用并选择片库根目录；仅配置 [Cloud 连接](/guide/cloud-sync)不会产生媒体库条目。

### 同步后仍找不到影片

确认「来源」「状态」与搜索词没有将条目过滤掉，检查上次同步时间，再针对该来源重新同步。115 筛选下无条目时，回到 115 设置检查片库根目录；服务器条目缺失时，检查服务器可达性和资料库同步开关。

### 看得到卡片却无法播放

先在相应服务中确认文件和访问权限。Emby / Jellyfin 检查服务器地址、令牌及媒体服务器运行状态；115 检查授权、账号状态以及文件是否能取得播放流。重新同步索引不等于修复失效的播放授权。

### 为什么这里没有本地磁盘文件或 Cloud 媒体源？

扩展媒体库的来源是 Emby、Jellyfin 和 115 片库目录，不扫描设备上的本地影片文件。需要本地扫描时阅读[桌面端本地媒体库](/desktop/local-library)；需要同步扩展记录时阅读 [Cloud 同步](/guide/cloud-sync)。两者与当前媒体库是不同功能。
