# 浏览器扩展连接 Cloud 与同步记录

适用于已安装 JavdBviewed 浏览器扩展、准备连接自己部署的 JavdBviewed-Cloud 的用户。扩展 `v2.1.3` 的「Cloud 多端同步」页面提供连接、设备管理和记录同步；该页面仍标注功能在测试中，首次使用前请先保留一份本地或 WebDAV 备份。Cloud 服务已核实的正式版本为 `1.2.9`；[部署与初始化](/cloud/deployment)和[升级备份](/cloud/backup-upgrade)是服务端流程，不在扩展设置页执行。

## 连接自建 Cloud

1. 确认 Cloud 服务已启动，并记下从当前浏览器**实际可访问**的服务地址。如果只在部署机器上使用，可填写本机映射地址（例如 `http://127.0.0.1:18080`）；其他设备上的浏览器不能用自己的 `127.0.0.1` 访问那台机器，请按[连接说明](/cloud/connections)配置可达地址与 HTTPS。
2. 在扩展仪表盘打开 `设置 → Cloud 多端同步`，到「连接服务」区域点击「编辑连接」。一次只配置一个自建 Cloud 服务。
3. 填写「Cloud 地址」「本机设备名称」及 Cloud 管理员账号和密码。设备名称会显示在登录设备列表中；设备 ID 由扩展管理，无需手动生成或复制。
4. 点击「测试连接」。成功提示表示服务可达、账号已登录，**尚未执行同步**。如果只点击「保存连接」，也不会自动完成本次登录或同步；保存后可从服务摘要卡继续连接和同步。
5. 返回「状态总览」查看服务、登录状态。首次同步前，建议确认本地备份已保留，再从「连接服务」摘要卡执行「立即同步」。

不要将 Cloud 管理员密码或扩展备份公开到 Issues。修改 Cloud 账号密码后，如提示会话失效，在「编辑连接」中更新凭据并重新「测试连接」。

## 查看与管理设备

登录后打开「已登录设备」，点击刷新查看同一 Cloud 账号下的客户端。本机条目会标为「本机」；可以撤销不再使用的**其他**设备，本机退出则使用连接区域的「退出登录」。设备名称是显示用的，设备 ID 与扩展「关于」页保持一致。

撤销设备登录可能使该设备需要重新验证账号；遇到陌生设备时，先检查账号安全，不要将设备 ID 或会话信息公开。

## 同步与检查结果

1. 在「连接服务」摘要卡点击「立即同步」。等待进度提示完成，再查看状态总览的上次同步时间以及同步结果；失败时保留提示信息，先检查连接和登录，不要反复清空本地数据。
2. 登录后，「同步设置」可以开启或关闭「后台自动同步」，并选择 15 分钟、30 分钟、1 小时或 3 小时间隔。浏览器需要允许扩展后台运行；关闭后台同步后仍可手动执行「立即同步」。
3. 扩展内**没有逐类同步范围开关**。同步范围说明包括视频状态、演员、清单、新作品与订阅、资料、搜索方案和部分显示/同步偏好。不要将未完成任务或登录会话当作已经在其他设备恢复。

运行/磁力日志、磁力缓存、Emby 本机库、遥测和登录会话令牌不属于这里的记录同步范围。同步的是扩展支持的记录与相关设置；**Cloud 媒体源不是这个页面的同步对象**，也不意味着把本地影片文件上传到 Cloud。客户端如何接入媒体源，应阅读对应的[桌面端媒体源](/desktop/sources)或[Android 媒体源](/mobile/sources)指南。

## 无法连接或同步时

| 现象 | 先检查什么 |
| --- | --- |
| 地址格式无效、服务健康检查失败 | 核对 Cloud 地址、服务是否运行、端口及浏览器网络是否可达；本机地址仅对同一设备有效。跨设备接入按[连接说明](/cloud/connections)检查 HTTPS 与网络限制。 |
| 地址可达，但账号或密码无效（401/403） | 在「编辑连接」更新管理员凭据，点击「测试连接」重新登录；改密可能使旧会话失效。 |
| 测试连接成功，却没有同步结果 | 「测试连接」不执行同步；从服务摘要卡点击「立即同步」，并查看进度和结果提示。 |
| 后台同步没有按预期运行 | 确认已登录、后台自动同步已开启，并检查浏览器是否允许扩展后台运行；先手动同步以缩小排查范围。 |
| 设备或记录与预期不一致 | 刷新设备列表与同步结果，先保存本地备份，再检查是否连接到预期的 Cloud 服务；不要盲目覆盖数据。 |

Cloud 服务自身出现异常时，参阅 [Cloud 排查问题](/cloud/troubleshooting)。需要反馈扩展问题可到 [公开 Issues](https://github.com/JavdBviewed/JavdBviewed/issues)，请隐去账号、密码、访问令牌和私人记录。

## Cloud 同步与 WebDAV 备份

Cloud 用于连接自建服务并同步扩展支持的记录；[WebDAV](/guide/webdav-sync)提供独立的备份与恢复路径，两者**互不替代**。Cloud 界面将 WebDAV 视为冷备份兜底；重要操作前继续保留本地导出和可用的 WebDAV 备份。

扩展备份不代替 Cloud 服务端备份。升级 Cloud `1.2.9` 前，须将数据库所在的完整数据目录和 `vault.key` 一起备份；升级后首次登录可能涉及旧会话迁移，回退旧版不能读取 v2 密文。操作前阅读 [Cloud 备份与升级](/cloud/backup-upgrade)。Cloud 媒体访问也不属于扩展 WebDAV 备份功能。
