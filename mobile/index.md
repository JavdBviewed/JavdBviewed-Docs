# Android 使用指南

JavdBviewed Android 是**原生 Kotlin 应用**，在手机上连接自己的 Cloud 和媒体源，浏览、播放影片，并管理下载及本地文件。它不是浏览器扩展，也不是 Clients 仓库中 `apps/mobile` 的 TypeScript 骨架；已发布的 Android 安装包来自原生 `apps/android` 工程。

## 当前可安装版本

截至 **2026 年 11 月 6 日**，已核实公开 Release 可获取的 Android 稳定版是 **1.0.2（`mobile-v39`，versionCode 39）**。该 Release 提供三种架构 APK 及一个 universal APK，每个 APK 另有 SHA-256 校验文件：

| 安装包 | 适用情况 |
| --- | --- |
| `app-arm64-v8a-release.apk` | 设备支持 `arm64-v8a` 时选择 |
| `app-armeabi-v7a-release.apk` | 设备使用 `armeabi-v7a` 时选择 |
| `app-x86_64-release.apk` | 使用 `x86_64` 的设备或模拟器 |
| `app-universal-release.apk` | 不确定设备架构时使用；文件更大 |

**不要根据文件名猜架构。**在安装前查看设备的 ABI 信息，或选 universal 包；每次都要核对下载文件属于 `mobile-v39`，再使用同一 Release 的校验文件检查 SHA-256。具体步骤见[安装 Android 应用](/mobile/install)。

> [!WARNING]
> 本地稳定清单已写 **1.0.3 / `mobile-v42`**，但截至上述核查日期，公开 Release 和对应 APK 链接返回 404。**不能把清单中的 1.0.3 当作当前可下载安装包**。等官方 Release 及资产均可核实时再更新安装指引；不要从第三方来源寻找同名 APK。

目前没有已核实的 iOS 或 TV 正式下载入口。本页只说明 Android 应用，不把桌面客户端、Android 模拟器或 TV 骨架当作其他平台的正式安装包。

## 从安装到播放

1. **安装应用**：选择对应架构的 `mobile-v39` APK，核对来源和 SHA-256，安装后打开应用。详见[安装与首次登录](/mobile/install)。
2. **连接 Cloud**：首次打开先填写自己的 Cloud 服务器地址和账号并登录，登录成功后进入主界面。**1.0.2 不提供绕过登录直接进入主界面的流程**；本地媒体源或下载数据不会因显示登录页而被自动清空。
3. **添加媒体源**：在底栏打开 **资源库**，添加从手机可访问的源，或查看从 Cloud 同步来的配置。服务器地址、账号与可达性由所选源决定，见[连接媒体源](/mobile/sources)。
4. **浏览并播放**：在资源库打开已有源，或者在 **媒体库** 找影片；确认影片可访问后开始播放。播放器、网络与下载管理见[播放与下载](/mobile/playback)。
5. **查看本地内容**：已下载文件与本地目录需要使用相应的本地源或下载中心；它们与 Cloud 索引、服务器上的媒体库不是同一份文件列表。见[媒体库与本地文件](/mobile/library)。

这里的 Cloud 用于进入应用和连接自己的同步实例，**不是**存放所有影片文件的公共流媒体服务。先确认手机能访问你的 Cloud；媒体源能否播放，还要另外检查对应服务器或本地文件是否可访问。不要把 Cloud 地址填进 Emby、WebDAV 等媒体源的服务器地址栏。

## 认识主界面的三个入口

| 底栏 | 用来做什么 | 首次进入时应检查 |
| --- | --- | --- |
| **资源库** | 查看已保存的媒体源，按源浏览目录或影片；右下角可添加源 | 媒体源列表是否有可访问的项目 |
| **媒体库** | 汇总可用的影片与云端索引，浏览“全部影片”等列表 | 空列表时先检查源、Cloud 同步和影片访问权限 |
| **我的** | 查看 Cloud 连接和与本机使用相关的设置 | 是否登录到预期的 Cloud 实例 |

媒体库里出现 Cloud 索引不代表原视频已下载到手机；在线播放需要能访问源文件。相反，下载中心有任务或本地目录里有文件，也不代表它们已进入 Cloud 的影片索引。

**版本区别**：1.0.3 的发布说明提到“全部影片”聚合有视频文件的本地下载源；但其公开安装包在上述日期尚不可核实。使用**已核可安装的 1.0.2** 时，不要按此 1.0.3 行为寻找下载影片：从下载中心和相应本地源查看本机内容，详情见[媒体库与本地文件](/mobile/library)。

## 常见起步问题

| 遇到的情况 | 先检查 |
| --- | --- |
| 安装包提示不适用于设备 | APK 的 ABI 是否匹配；不确定时使用该 Release 的 universal 包 |
| 安装前无法确认包的真伪 | 回到正式 Release、核对文件名与同版 SHA-256；不要安装来路不明的 APK |
| 启动后只显示 Cloud 登录页 | 这是 1.0.2 的入口；检查 Cloud 地址、网络以及实例账号，不要先清除应用数据 |
| 登录了但资源库没有源 | 查看是否从 Cloud 同步成功；也可在资源库添加手机可访问的源 |
| 媒体库没有电影 | 区分云端索引、服务器媒体库及本机下载；先确认所选源确实有可访问的影片 |
| 影片列表可见却不能播放 | 检查媒体源凭据、网络和实际文件；参见[播放与下载](/mobile/playback) |
