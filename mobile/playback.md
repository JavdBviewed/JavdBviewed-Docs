# Android 播放与下载

本文对应公开可获取的 **Android 1.0.2（`mobile-v39`）**。播放需要手机能访问实际媒体源或已下载的本机文件；登录 Cloud、看到作品索引，都不等于视频已经存到手机。开始前先按[媒体源指南](/mobile/sources)添加并测试可访问的源。

> [!NOTE]
> 本地稳定清单写有 1.0.3，但截至 2026 年 11 月 6 日，其公开 Release 与 APK 无法核实。本页只描述 1.0.2 固定发布代码已经提供的入口；不把 1.0.3 的本地下载聚合行为当成当前安装包功能。

## 找到要播放的影片

- **Emby/Jellyfin 媒体库**：在底栏 **媒体库** 查看可用电影，点开影片详情，确认信息加载完成，再点 **播放**。播放前应用会向对应媒体服务器解析视频地址。
- **SMB、WebDAV 或本地文件**：在底栏 **资源库** 点已经保存的源，逐级打开目录，选择具体视频文件。该入口从文件解析播放地址，不要求它先出现在“全部影片”。
- **115**：从资源库打开已经可用的 115 源并浏览文件；若账号或播放地址获取失败，先处理对应源的登录状态。115 扫码入口是否可用取决于安装包配置，见[115 源说明](/mobile/sources)。
- **本地下载**：已完成的下载由本机的“本地下载”源读取，选择文件时解析为本地文件播放地址；不需要再次向原媒体服务器请求同一个远端视频流。

如果列表里只有来自 Cloud 的作品索引，但没有可访问的视频源，不要把索引条目当成可播放文件。媒体库列表和源目录属于不同浏览方式，详见[媒体库与本地文件](/mobile/library)。

## 开始与控制播放

1. 先确认手机当前网络能访问媒体服务器；使用 SMB 时还要确认共享目录权限，使用本地文件时检查 Android 的目录读取授权。
2. 在电影详情点 **播放**，或从资源库目录点具体文件，等待播放器加载。初次加载失败时先查看屏幕上的错误信息，再返回源列表检查连接。
3. 播放器提供播放、暂停、进度定位和关闭等操作。文件是否能正常起播仍取决于源提供的视频地址、权限和实际文件，不保证所有封装或编码都兼容。
4. 看完或退出后返回媒体库，需要继续观看时可以查找 **继续观看** 区域，或回原媒体源重新选择影片。

固定 tag 中，“继续观看”区域可从记录或媒体服务器获取候选影片，播放过程也会记录进度。**不要把栏目显示与“点击后一定从上次时间点自动起播”画等号**；重新进入时以播放器实际位置为准，需要时手动定位。源删除、影片移动、网络不可达或同步未完成时，继续观看记录也可能无法重新解析视频。

播放进度的本机记录与 Cloud 同步有各自流程。若预期在另一台设备看到进度，应确认当前 Cloud 登录、同步状态和影片标识一致；只在此手机上开始播放，不表示远端已成功收到全部进度。详情见[媒体库与本地文件](/mobile/library)。

## 创建下载任务

1. 在能正常打开的影片详情页点 **下载**；播放器在已解析且允许下载的视频源上也会显示 **下载**。若按钮不可用或未出现，不要推断所有源都支持这一入口。
2. 应用先解析源的视频地址，再把下载加入任务列表。看到“已加入下载”只代表任务已创建，**不是文件已下载完成**。
3. 在底栏 **我的** 打开 **下载中心**，查看任务状态和进度。下载中心列表中，点正在下载的任务可暂停；点暂停、排队或失败的任务可再次尝试。
4. 任务完成后，从 **资源库 → 本地下载** 浏览已经保存且可识别的视频文件，点文件从本地解析并播放。

下载会消耗设备空间与网络流量。若影片需要原源的访问权限，创建任务时仍要能解析其地址；下载中网络断开、源地址过期或权限变化都可能导致任务失败。恢复任务后继续看进度，**不要假定失败的任务会自动从原字节位置接着下载**。

> [!WARNING]
> 下载中心长按任务可进入取消或删除操作。固定版本的**删除任务会尝试删除该任务对应的已下载文件和临时文件**；如果要保留本地影片，不要将“删除任务”当作仅隐藏列表项。

## 下载文件与在线播放的区别

| 路径 | 视频从哪里来 | 网络或登录依赖 |
| --- | --- | --- |
| 电影详情或远端源目录播放 | 在播放时向 Emby/Jellyfin、SMB、WebDAV 或其他实际源解析 | 需要手机当时能访问源及其有效凭据 |
| 下载任务运行中 | 从已解析的视频地址取得数据并写入手机 | 仍依赖源地址与网络；排队不代表已有完整文件 |
| 本地下载源播放 | 选择手机上已经存在的视频文件，从本地文件地址解析 | 本机文件必须仍在且格式可识别；不应误当远端在线播放 |

1.0.2 的 **媒体库 → 全部影片** 不应被当作所有本地下载的自动列表：1.0.3 的发布说明才描述了本地下载源聚合，但该版安装包在上述核查日期尚不可用。找不到已下载文件时，先查 **下载中心** 的完成状态，再看 **资源库 → 本地下载**，不要反复点击远端电影以判断是否下载完成。

## 常见问题

| 表现 | 排查顺序 |
| --- | --- |
| 列表为空 | 是否已经连接并启用媒体源，手机网络是否能访问服务器；Cloud 索引并不等于可播放文件 |
| 详情页加载失败或没有播放入口 | 返回资源库确认源仍存在、服务器在线且当前账号有影片访问权限 |
| 目录能打开，但点击文件不能播 | 读取权限、网络共享和文件是否仍在；再看播放器显示的具体错误 |
| 播放时提示源地址过期或连接失败 | 重新从源列表打开影片以解析新地址；核对网络、登录信息及服务器状态 |
| 下载显示排队却找不到本地文件 | 到下载中心等任务完成，再从“本地下载”源浏览；排队中并未得到完整文件 |
| 下载中断、暂停或失败 | 点任务重试，观察进度和错误；确认磁盘空间、源可达性及账号权限 |
| 已完成任务但本地下载列表为空 | 核对任务文件是否还存在、是否为可识别视频格式；删除任务可能连文件一起移除 |
| 找不到上次观看位置 | “继续观看”不保证自动从断点起播；核对是否选了同一影片、同一媒体源，再手动定位 |

返回[Android 使用指南](/mobile/)；具体源配置见[连接媒体源](/mobile/sources)，本地文件与索引见[媒体库与本地文件](/mobile/library)。
