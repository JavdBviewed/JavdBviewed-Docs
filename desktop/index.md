# 桌面端使用指南

JavdBviewed 桌面端是独立的 Windows 客户端，不需要先安装浏览器扩展。它可以扫描本机视频目录、按番号获取作品信息，并连接媒体源浏览和播放影片。需要让多个设备共享记录或媒体源配置时，再连接自己部署的 Cloud。

本页介绍 **Windows x64 桌面端 1.0.0** 的首次使用路径。其他系统的桌面安装包不在这一版的稳定发布清单中；Android 请看 [移动端指南](/mobile/)。

## 下载与安装

1. 从正式发布仓库下载 [Windows x64 安装包（1.0.0）](https://github.com/JavdBviewed/JavdBviewed-release/releases/download/desktop-v1.0.0/JavdBviewed-desktop-1.0.0-win-x64.exe)。安装包名为 `JavdBviewed-desktop-1.0.0-win-x64.exe`。
2. 在 Windows 上运行安装包，完成安装后打开 JavdBviewed 桌面端。
3. 进入应用，先确认能够看到本地影片和媒体源相关入口；无需先打开扩展管理页或导入浏览器数据。

发布详情见 [桌面端 1.0.0 发布说明](https://github.com/JavdBviewed/JavdBviewed-release/blob/main/releases/desktop/v1.0.0.md)。下载或安装失败时，先检查系统是否为 Windows x64，再核对下载文件与正式发布清单中的文件名及 SHA-256；完整步骤见 [安装与校验](/desktop/install)。

> [!NOTE]
> 这个安装包只面向 Windows x64。发布页中的 `.blockmap` 和 `latest.yml` 是更新所用文件，不是安装程序。安装入口以发布仓库的稳定清单为准。

## 先分清三处数据

| 在哪里操作 | 用途 | 是否要先连接 Cloud |
| --- | --- | --- |
| **本地影片** | 扫描这台电脑上的视频目录、识别番号、刮削信息、确认入库 | 不需要；未登录时先保存本机映射，登录后再同步 |
| **媒体源连接** | 添加 Emby、Jellyfin 等媒体源，在应用中浏览影片并播放 | 本机添加不需要；也可以在登录 Cloud 后同步已有的媒体源配置 |
| **Cloud 同步** | 将作品记录、进度等同步到自己部署的 Cloud，并在设备间共用配置 | 需要先有可访问的 Cloud 实例和管理员账号 |

本地目录扫描不是给 Emby/Jellyfin 添加媒体源；确认扫描结果也不会把影片自动导入媒体源的影片列表。若只想查看本机文件，可以先使用本地影片；若想浏览媒体服务器并播放，需另行添加媒体源。桌面端的媒体源连接也不同于[浏览器扩展的 Emby 页面增强](/guide/emby-integration)。

## 首次连接 Cloud（按需）

已经自建 Cloud、希望跨设备同步时，先确保桌面端能访问 Cloud 地址。没有 Cloud 的用户可以先跳到下一节扫描本地影片；Cloud 不替代这台电脑上的视频目录或媒体服务器。

1. 打开桌面端设置中的 **Cloud 同步**。
2. 填写你自己的 Cloud 服务器地址和本机设备名，使用管理员账号 `admin` 及该实例的密码登录。Cloud 是单属主实例，不要尝试注册第二个账号。
3. 查看连接状态，需要时使用 **立即同步**。登录后从 Cloud 同步来的媒体源会出现在本机的媒体源列表中；本机对媒体源的改动也可回写 Cloud。
4. 在 **媒体源连接** 中查看同步后的条目及其连接状态。若没有媒体源，仍可自行在本机添加。

如果登录失败，先确认 Cloud 运行正常、地址可从这台电脑访问，且使用的是该实例的管理员密码。公网访问 Cloud 应使用 HTTPS 反向代理；自部署步骤见 [Cloud 部署指南](/cloud/deployment)，连接与设备问题见 [Cloud 连接说明](/cloud/connections)。不要把账号密码写在共享截图或公开问题描述中。

## 扫描、刮削、确认入库

首次整理本机影片时，按以下顺序操作：

1. 在 **本地影片** 中选择 **浏览…** 或填写这台电脑上的视频目录路径，使用 **添加目录** 开始扫描。应用会列出识别到的视频文件及其番号；目录有新文件时可以 **重扫**。
2. 逐条检查文件名与识别出的番号。没有识别出番号的条目不能确认入库，先核对文件命名与路径，避免把错误作品写入记录。
3. 对需要补全标题、封面等信息的条目使用 **刮削**。刮削会按已配置的引擎查询；失败时检查引擎和网络，再决定是否重试或保留待处理状态。
4. 核对结果后使用 **确认入库**。条目状态变为“已入库”；同一番号的云端实体会避免重复推送。未登录 Cloud 时，本机映射仍会先保存，并提示待登录后同步到云端。
5. 不想收录的结果可以排除。不要把目录扫描结果直接当成已同步的云端记录；留意每条的状态和操作反馈。

本地目录的扫描、刮削与入库细节见 [本地影片整理](/desktop/local-library)。如果刮削无结果，先区分是“没有识别出番号”还是“有番号但搜索失败”，再查对应步骤。

## 连接媒体源并播放

要浏览 Emby/Jellyfin 上的影片，可在 **媒体源连接** 中添加自己的服务地址和所需凭据；已经从 Cloud 同步媒体源配置的用户，可先查看该列表，避免重复添加同一服务器。

连接后进入媒体库，确认影片列表或详情能正常加载，再选择影片播放。播放依赖媒体源提供可用的文件或播放地址；播放进度的跨设备同步则需要 Cloud 连接正常。看完后，应用可将作品标记为真实已看；遇到播放失败先排查媒体源连接、凭据与影片本身是否可访问。

媒体源的添加、浏览与播放路径见 [媒体源与播放](/desktop/sources)。本地扫描与媒体服务器浏览是两条入口，请按影片实际存放的位置选择。

## 完成后检查

首次使用不必一次做完所有配置。按实际需要检查以下结果：

- **只整理本机影片**：本地影片页显示添加的目录和扫描到的文件；有番号的条目可以刮削或确认，已确认的条目显示“已入库”。
- **已经连接 Cloud**：Cloud 同步页显示连接状态；执行“立即同步”后再查看反馈。本机新增的入库记录若先前未登录，可在连接后等待同步，不必重复确认同一条目。
- **已经添加媒体源**：媒体源列表中能看到自己的服务器；媒体库加载出服务器上的影片时，选择一部可播放的影片验证连接。仅有本地扫描记录，不代表服务器媒体库已经接入。

### 看不到预期结果时

| 表现 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 扫描列表没有影片 | 目录是否在这台 Windows 电脑上、路径是否正确、目录中是否有可识别的视频文件 | 回到本地影片页重扫，见[本地影片整理](/desktop/local-library) |
| 文件出现但没有番号 | 文件名是否包含可识别的番号 | 先核对命名；没有番号的条目无法确认入库 |
| 刮削失败或资料不符 | 识别番号是否正确、查询引擎是否可用 | 不要直接确认错误资料，先按[本地影片整理](/desktop/local-library)核对 |
| Cloud 登录或同步失败 | 自建 Cloud 是否可访问、管理员密码是否正确、是否有操作反馈 | 看[Cloud 连接说明](/cloud/connections)；本机扫描结果不会因登录失败而变成媒体源 |
| 媒体库没有影片或无法播放 | 是否已添加并启用媒体源、服务器上是否有可访问的影片 | 看[媒体源与播放](/desktop/sources)，不要用本地扫描条目代替媒体源条目 |
